    Required & Optional Columns

    Column Header Status Description & Cell Rules
    Course Code Required Course ID (e.g. CSC3CR201 or CSC3CR201_G1)
    Course Name Optional Display title of the course
    Semester Optional Semester number (e.g. 3)
    Category Optional Category name (e.g. MAJOR, AEC)
    Slot Columns
